☁️ Real Cloud Storage - Global Uploads

Files uploaded to Catbox.moe are already GLOBAL (no setup). For fully global list (everyone sees same uploads), add free Supabase + Cloudinary below. Takes 2 mins, free.

How to make uploads GLOBAL for everyone:

1. Catbox (already global, no setup): Audio & cover uploaded to catbox.moe → global URL, anyone can download if they have link.
2. For global list (everyone sees same tracks):
- Create free Supabase account → New Project → Table `songs` with columns: title, artist, genre, cover_url, audio_url, audio_name, created_at
- Copy Project URL + anon key → paste above → Save → Now every upload saves to Supabase and appears globally to all visitors.
3. Cloudinary (optional, better than Catbox): Create free Cloudinary → Settings → Upload → Add unsigned preset → paste Cloud Name + Preset above.
Without Supabase: files are global but list is local per device. With Supabase: fully global.
